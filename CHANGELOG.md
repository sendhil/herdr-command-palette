# Changelog

## [0.1.1] - 2026-07-19

### Added

- A polished live-results hierarchy with a focused workspace-to-tab-to-agent
  rail, fuzzy-match highlighting, section counts, and responsive metadata.
- Distinct working, blocked, done, idle, and unknown status treatments, with
  blocked agents prioritized in the empty palette.

### Changed

- Refined selection, forms, footer hints, focused-session markers, and compact
  layouts for a clearer terminal-native visual hierarchy.
- Recommended `Cmd-Shift-P` with conditional WezTerm forwarding that preserves
  WezTerm's own `Ctrl-Shift-P` command palette.

## [0.1.0] - 2026-07-19

### Added

- Contextual Herdr commands and installed plugin actions in a keyboard-first
  popup.
- Universal workspace, tab, and agent search with scoped queries and exact-ID
  stale-target safety.
- Focused-agent rename, bounded rendering and input, and bounded Herdr CLI
  process handling.
- macOS source installation through Herdr.
