# Security Policy

## Supported versions

`v0.1.x` is the currently supported release line.

## Reporting a vulnerability

Do not open a public issue for a suspected vulnerability. Report it privately
through [GitHub private vulnerability reporting](https://github.com/sendhil/herdr-command-palette/security/advisories/new)
for `sendhil/herdr-command-palette`.

Include reproduction steps, expected and actual behavior, impact, Herdr and
macOS versions, and minimal logs with secrets removed.

This plugin executes Herdr CLI commands with the user's permissions and has no
sandbox. Reports involving command execution, plugin installation,
configuration, process cleanup, or untrusted output are especially useful.
